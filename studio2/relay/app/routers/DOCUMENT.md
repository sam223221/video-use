# studio2/relay/app/routers/ — HTTP surface (18 routes: Step 1's 8 + Step 3's 5 + M2's 3 + model picker's 2)

All errors use the v1 envelope `{detail:{error:{code,message}}}` (the PWA
unwraps via `normalizeError`). State-changing endpoints are POST + JSON body
(CSRF posture); everything under `/api/*` except `login`/`me`/`tls/info`
requires the session cookie. **NO HSTS** anywhere (the http bootstrap origin
must stay reachable).

## Files / routes

| File | Routes | Notes |
|---|---|---|
| `deps.py` | — | `require_session` (reads `__Host-studio2_session` FIRST, then `studio2_session`; raises 401 `unauthorized`), `current_user`, `error_response`/`http_error`. v1 verbatim minus `require_session_dir` (no server-side sessions exist). |
| `auth.py` | `POST /api/login`, `POST /api/logout`, `GET /api/me` | Scheme-aware dual-name cookies (https → `__Host-`, Secure+Path=/+no Domain; http → plain), remember=false → session cookie + 12h token. Uniform 401 on bad creds (constant-time compare + anti-enumeration dummy). Logout clears BOTH names (documented v1 limitation: an http-origin logout cannot clear the `__Host-` cookie). `/api/me` is public: `{authenticated, username, asset_version, secure_url}` — `asset_version` regex-parsed read-only from `pwa/app.js` (mtime-cached, None while the PWA isn't deployed). |
| `tls.py` | `GET /ca.crt`, `GET /setup`, `GET /api/tls/info` | All public (public material only, zero user input). `/ca.crt` serves the SHARED v1 CA as DER (`application/x-x509-ca-cert`, `Content-Disposition: inline` for the iOS profile flow; byte-identical to v1's). `/setup` → `pwa/setup.html` no-cache; **graceful 404 `setup_unavailable`** while the parallel PWA build hasn't landed (Step-1 brief contract). `/api/tls/info` never-5xx: `{enabled, https_url, host_local_url, http_url, ca_sha256, leaf_expires}` with nulls on failure. |
| `status.py` | `GET /api/status` | Cookie-gated. `{ok, version, agent_auth:{mode,detail}, agent_model:"<id>"|"default", bridge:{devices_connected}, transcribe:{configured, enabled, daily_remaining:{calls, audio_mib}}}`. **Guarded-lazy stubs:** agent_auth/bridge resolve through lazy imports of the Step-3 modules (`agent/env.py`, `core/bridge.py`); **M2** adds the `transcribe` block via the same pattern (`core/transcribe.status_summary()` — presence only, NEVER the key; a broken sub-probe degrades to `configured:false`, never 500s status); the **model picker** adds `agent_model` (`core/agent_model.current()` — the GLOBAL selection for display; lazy + degrades to `"default"`, never 500s). The PWA gates the Transcribe affordance on `transcribe.configured`. |
| `client_log.py` | `POST /api/client-log` | v1 contract VERBATIM: 64KiB streamed body cap → 413 `payload_too_large`; >200 events or garbage → 400 `invalid_body` (manual parse, `ValueError` AND `RecursionError` caught); never-500; deliberately NO Content-Type requirement (sendBeacon `text/plain` tails — do not "fix"); per-event sanitization via `applog.sanitize_log_value`; malformed events skipped + counted, not fatal; `ClientDisconnect` → 499 `client_disconnected`. |

| `bridge.py` | `GET /api/bridge/events`, `POST /api/bridge/result` | **The bridge surface (arch §2.3/§3).** The SSE stream is cookie-gated (EventSource sends cookies same-origin; read-only GET = CSRF-safe): `: connected` → `hello` (`id: 0`, `{device_id, server_boot_id, replayed}`) → replayed still-pending `command` frames (original seqs, `Last-Event-ID`-filtered; missing header replays all pending) → live `command` frames → `: hb` every 20 s. `device_id` regex `^dev_[0-9a-f]{16}$` (400 `invalid_device_id`); 8-streams/user cap pre-checked as a real 409 `too_many_devices` (re-checked at generator registration → in-stream `error` frame for the race window); superseded streams end with `: superseded`. The result POST mirrors the client_log pattern: streamed RAW-byte cap **2 MiB** (`_RESULT_MAX_BYTES`; raised from 512 KB for Agent Vision's `view_frames` image results — plan 2026-06-13 §3, a LOCKSTEP pair with the PWA `bridge.js` cap, both authenticated, the accepted+documented DoS-budget bump) → 413 `payload_too_large`; manual JSON parse → 400 `invalid_body` (shape per §3.2: ids regex'd, `ok` bool, `result` object-only, `error{code,message}` snake-case code + capped message); resolve must match the authenticated user AND device_id → else one uniform benign 409 `no_pending_command`; `ClientDisconnect` → 499. |
| `chat.py` | `POST /api/chat`, `GET /api/chat/attach`, `POST /api/chat/cancel` | **The agent turn over the turn-survival buffer (arch §2.2).** POST `{message, project_id, device_id}` (ids regex'd; empty message 400; 100k-char DoS cap → 413) starts the DETACHED turn (`turns.start_turn`) and streams the buffer — the response is a PURE READER; 409 `turn_in_progress` on a concurrent turn for the same key. Attach replays the live/most-recent buffer from `after_seq` (then live-follows to `turn_end`); 404 `no_active_turn` when none/swept. Cancel = `bridge.cancel_for_turn` (unblocks ask_user-parked dispatchers FIRST) + SDK interrupt → `{cancelled: bool}` (false when nothing live — a cancel never CREATES a session). Event vocabulary EXACTLY §2.2, every frame `id:`-seq'd; NO `ask_user` event (questions travel the bridge); NO history endpoint (transcript lives on the device). The agent import is inside the handlers so a broken SDK install breaks `/api/chat`, not boot. |
| `transcribe.py` | `POST /api/transcribe`, `GET /api/transcribe/{job_id}`, `DELETE /api/transcribe/{job_id}` | **THE one media exception (M2, arch §3 + §8.1).** Cookie-gated, v1 envelope, never-500. **POST**: query params validated (`project_id` `^prj_[0-9a-f]{12}$`, `clip_id` `^clip_[0-9a-f]{8}$`, `duration_s` finite 0<d≤180min soft cap, optional `language` `^[a-z]{2,3}$`) BEFORE any byte is read; content-type STRICTLY `audio/mp4` (base subtype, params ignored) else 400; the cost guards (`core/transcribe.register` → 403 `transcribe_disabled` / 409 `transcribe_busy` / 429 `daily_cap_reached`) run BEFORE the body streams; then the RAW body is streamed straight to a job-named spool with the hard 256 MiB cap enforced **on the fly** — 413 `audio_too_large` the instant the cap is crossed (partial spool deleted, slot released, body never fully buffered — proven over a real socket), `ClientDisconnect` → 499 (spool deleted, NO EL call, NO cost), empty body → 400. On full receipt: detached EL task launched + **202** `{job_id, est_cost_usd}` (the work now survives the phone locking). **NO multipart surface** — only `request.stream()`; no `UploadFile`/`Form`/`File`/`request.form()`; python-multipart stays out (M1 §8.5 property verbatim; the EL multipart is built OUTBOUND by httpx in `core/transcribe.py`). **GET** poll: `transcribing`/`done` (with the §4.2 transcript)/`error`; uniform 404 `job_not_found` for unknown/foreign/expired/post-restart (anti-IDOR, like bridge's `no_pending_command`); first `done` fetch marks delivered (+120 s grace). **DELETE** best-effort cancel → `200 {cancelled:bool}`; same uniform 404. |
| `agent.py` | `GET /api/agent/model`, `POST /api/agent/model` | **The GLOBAL agent-model picker (plan 2026-06-13; the 8th router).** Cookie-gated, v1 envelope, no secret read/written/returned. **GET** → `{current:"<id>"|"default", available:[{id,label,hint}], applies_to:"new conversations"}` — the current GLOBAL selection + the verified allowlist (`core/agent_model`). **POST** `{model}` → 400 `invalid_model` when `model` is missing / non-string / not on the allowlist (NO free text — security §7), else persist to `.runtime/agent_model.json`, bump the model-version (so `agent/session.py` evicts+rebuilds the cached session on its NEXT turn — an in-flight turn finishes on its old model), return `{current, available}`. GLOBAL scope (USER decision): any logged-in household user may read/change it; no per-user/per-project state. Subscription invariant preserved — the picker selects WHICH subscription model, never billing mode; no ANTHROPIC_API_KEY introduced. |
